Getting started

From clone to studio in three commands

terminal 
$ git clone https://github.com/lannguyen2903/OpenAgenticGame-Studios.git my-game
$ cd my-game
$ npm install -g @openai/codex # one-time
$ codex

› Run /start — the system asks where you are
  (no idea · vague concept · clear design · existing work)
  and guides you to the right workflow. No assumptions.

› Or jump in: /brainstorm · /setup-engine godot 4.6 · /project-stage-detect
